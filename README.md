# 🦊 FunSpeak Kids – Ứng dụng luyện nói tiếng Anh cho bé

Ứng dụng web tĩnh (HTML/CSS/JS thuần) giúp trẻ làm quen và luyện phát âm tiếng Anh qua video bài hát, mẫu câu giao tiếp, nhận diện giọng nói và trò chơi trắc nghiệm.

## 📂 Cấu trúc gói triển khai
- `index.html`: Toàn bộ giao diện, dữ liệu bài học và logic ứng dụng.
- `manifest.json`: Cấu hình Web App (PWA) để bé có thể thêm ra màn hình chính điện thoại/máy tính bảng.
- `.nojekyll`: Đảm bảo GitHub Pages phục vụ file nguyên bản không qua trình biên dịch Jekyll.
- `README.md`: Tài liệu hướng dẫn triển khai.

## 🚀 Cách triển khai lên GitHub Pages
1. Giải nén file `FunSpeak-Kids-GitHub.zip`.
2. Tạo repository mới (chế độ **Public**) trên GitHub, ví dụ `funspeak-kids`.
3. Tải toàn bộ các file bên trong thư mục giải nén (`index.html`, `manifest.json`, `.nojekyll`, `README.md`) lên thư mục gốc (root) của repository.
4. Vào **Settings → Pages** → tại **Source**, chọn **Deploy from a branch** → chọn nhánh `main` và thư mục `/ (root)` → nhấn **Save**.
5. Truy cập địa chỉ `https://<username>.github.io/funspeak-kids/` sau 1–2 phút.
